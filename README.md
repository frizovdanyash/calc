# Вектор

**Вектор** — открытый научный калькулятор для Android, который показывает не только ответ, но и путь к нему. Интерфейс, вычисления и история работают локально на устройстве.

## Карточка приложения

- **Название:** Вектор — калькулятор с решением
- **Package name:** `com.frizovdanya.vektor`
- **Кратко:** Научный калькулятор с решениями столбиком, уравнениями и конвертером единиц.
- **Лицензия:** MIT
- **Автор:** [@frizovdanya](https://t.me/frizovdanya)
- **Android:** версия 8.0 и новее

## Возможности

- Научный калькулятор: скобки, приоритет операций, проценты, степени, факториал, константы π и e.
- Тригонометрия в градусах и радианах; sin, cos, tan, обратные функции, корень, ln, log, abs и exp.
- Пошаговое сложение, вычитание, умножение и деление целых чисел в столбик, включая переносы, промежуточные произведения и остаток.
- Решение линейных и квадратных уравнений: действительные и комплексные корни, дискриминант и подстановка для проверки.
- Конвертер восьми категорий: длина, масса, температура, площадь, объём, скорость, время и данные.
- История вычислений с сохранением на устройстве и повторным открытием выражения.
- Настройка светлой, тёмной или системной темы, пяти акцентных цветов, точности ответа и режима углов.
- Без учётной записи, сетевых разрешений и отправки выражений на сервер.

## Сборка APK

Нужны JDK 17 и Android SDK с платформой Android 35. Открой проект в Android Studio либо выполни из корня репозитория:

```sh
./gradlew assembleDebug
```

Готовый APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`. Для запуска тестов:

```sh
./gradlew testDebugUnitTest
```

Сборка использует Gradle Wrapper, Android Gradle Plugin и Jetpack Compose. Исходный код, настройки проекта и тесты находятся в этом репозитории.

## GitHub Releases

Workflow в `.github/workflows/android.yml` проверяет сборку и тесты. При публикации тега вида `v1.0.0` он собирает подписанный debug APK и прикрепляет его к GitHub Release. APK подходит для установки и ознакомления; для публикации в Google Play рекомендуется собрать и подписать release-вариант собственным ключом.
