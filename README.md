# calculator

**calculator** - открытый калькулятор для Android. Для младших школьников есть простые примеры с пустой клеткой и объяснением обратного действия; расширенная алгебра вынесена отдельно.

## kарточка приложения

- **Название:** Calculator
- **Имя пакета:** `com.frizovdanya.vektor`
- **Кратко:** Калькулятор для учёбы: примеры столбиком, понятные уравнения и конвертер единиц.
- **Лицензия:** MIT
- **Создатель:** [@frizovdanya](https://t.me/frizovdanya)
- **Android:** 8.0 и новее

## Возможности

- Научный калькулятор: скобки, приоритет операций, проценты, степени, факториал, π, e, тригонометрические и логарифмические функции.
- Арифметика в столбик с переносами, промежуточными произведениями и делением с остатком.
- Простые уравнения для начальной школы: сложение, вычитание, умножение и деление с неизвестным числом в клетке, пошаговой подсказкой и проверкой ответа.
- Дополнительный раздел алгебры: линейные и квадратные уравнения, дискриминант и комплексные корни.
- Конвертер длины, массы, температуры, площади, объёма, скорости, времени и цифровых данных.
- История с повторным открытием выражений.
- Светлая, тёмная и системная темы; динамические цвета обоев на Android 12+ или один из пяти именованных акцентов; точность ответа и режим углов.
- Вычисления и история остаются на устройстве; приложению не нужны сетевые разрешения.

## Сборка APK

Нужны JDK 17 и Android SDK с платформой Android 35. Открой проект в Android Studio или выполни из корня репозитория:

```sh
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Запуск модульных тестов:

```sh
./gradlew testDebugUnitTest
```
